## 5. 执行策略与并行调用

采用 **“识别依赖 → 独立并行 → 汇合证据 → 核对结果”** 的执行方式。

**应并行：**
- 两个查询相互独立、输入参数已知，且工具允许并发时，可在同一轮调用 `{工具名A}` 与 `{工具名C}`。
- 已取得多个独立的 `{文档ID/接口ID/查询引用}` 后，可并行执行其详情读取。
- 同一工具支持批量参数时，**优先一次批量调用**，而非多次串行调用。

**必须顺序：**
- `{发现工具}` → 获得真实 `{ID}` → `{详情工具}` → 获得结果 → `{计算/验证工具}`。
- 分页或游标查询需要上一页返回参数时，必须逐页依赖执行。
- 有业务前置条件的写操作（若被授权）不得超前执行。

**禁止：** 为了并行而猜 ID、发送重复查询、混合不同统计口径、并发执行互相依赖的步骤。
