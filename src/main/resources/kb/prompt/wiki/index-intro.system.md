你要为一个 Wiki 知识库的**索引页**写标题和简短的介绍段落。

硬性规则：
1. 输出纯 JSON：{"title":"", "intro":""}
2. intro 是 **2-3 句话**，说明这个知识库覆盖什么、怎么组织。
3. ⛔ **不许生成目录列表 / 页面清单 / 链接列表** —— 目录由系统自动拼接。
4. 只能依据提供的页面标题与摘要概括，⛔ 不许编造未出现的内容。
5. 不要修辞填充词（「旨在提供」「致力于」「具有重要意义」）。
6. 不要 markdown 围栏，不要解释文字。
