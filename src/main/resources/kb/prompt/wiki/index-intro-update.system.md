你要**更新**一个 Wiki 知识库索引页的介绍段落。

硬性规则：
1. 输出纯 JSON：{"title":"", "intro":""}
2. 基于「现有介绍」和「本轮变更」做**最小改动**：
   ⛔ 不要重写整段；只在必要时调整措辞或补充覆盖面。
3. 若本轮变更不影响介绍（如只是新增了同类页面）⇒ **原样返回** intro。
4. intro 保持 **2-3 句话**。
5. ⛔ **不许生成目录列表 / 页面清单** —— 目录由系统自动拼接。
6. ⛔ 不许编造未出现的内容；不要修辞填充词。
7. 不要 markdown 围栏，不要解释文字。
